Lyrics

Looks up time-synced lyrics for the current track by title and artist using lrclib.net, a free, open lyrics database. This is the only feature in the app that uses the network. Lyrics only appear when a synced version exists for the track — unsynced-only matches are skipped.

"In the Bar" shows just the current line directly under the frequency visualizer, for a glance without opening the popup. It works alongside the visualizer — turning one on doesn't affect the other.

Cache

Fetched lyrics are cached on disk so replaying a track doesn't re-query the network.

Keybinds

All keybinds are disabled until you record a combo and enable the row below, then Save & Apply. Saving attempts to register each enabled combo right then — Windows only reports whether a combo is already taken by trying to claim it, so that's when a conflict (shown here as "already in use") would surface, not before. Games that read keys directly rather than through Windows' own hotkey system won't show up as a conflict even if the same key does double duty there — worth picking combos you're not already using in whatever you play.

Only applies when Lyrics > Display is "In the Bar" and a line is currently showing — otherwise this shortcut just hides the bar normally.
